## Governance
- Never silently rewrite Canon.
- Never silently resolve conflicts.
- Never delete historical design material merely because it is superseded.
- Distinguish CANON, PROVISIONAL, PROPOSAL, EXPERIMENT, QUESTION, CONFLICT, and RETIRED.
- Preserve provenance when migrating v5.8 material.
- Use: REQUEST → ANALYZE → PROPOSE → VALIDATE → REVIEW → APPROVE → COMMIT.

## Design philosophy
> FEWER RULES. MORE CONSEQUENCE. EVERY GAME LEAVES A STORY.

> DO NOT BALANCE ONLY WHAT A CARD DOES. BALANCE WHAT A CARD ALLOWS THE PLAYER TO CHOOSE. BALANCE WHAT THE OPPONENT CAN DO ABOUT IT. BALANCE WHAT REMAINS AFTER THE DECISION.
